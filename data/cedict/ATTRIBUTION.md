# CC-CEDICT

Chinese–English dictionary data for Chinese definitions and pinyin.

From [CC-CEDICT](https://cc-cedict.org/), published by [MDBG](https://www.mdbg.net/chinese/dictionary?page=cc-cedict),
licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Built by `scripts/build-cedict.mjs`.
Changes: split into 64 files by first character, pinyin converted to tone marks, cross-references
shortened (e.g. `CL:個|个[ge4]` → `Classifier: 个`). This data is shared under the same license.
